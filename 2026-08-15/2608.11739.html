G0.5: One Autoregressive Stream for Robot Reasoning and Action

Yicheng Liu, Zibin Dong, Baijun Ye, Tianyuan Yuan, Tao Jiang, Anqi Yang
abspdf

论文点评Review

G0.5 试图把被 VLM-as-encoder 架构（如π0.5 [4]）阉割掉的“思考”能力重新塞回动作生成流里，这招“复古”操作确实有点意思。它没搞花里胡哨的扩散头，而是死磕自回归，用一套权重通吃推理和动作，强行让 VLM 回归“决策者”本位。结果在 DROID 零样本迁移上干掉了π0.5 25 个百分点，确实有点东西，证明了“思考”不是累赘。但别高兴太早，它也不是万能药：面对低对比度半透明物体（如白色抽屉）时，表现反而不如基线，说明视觉鲁棒性仍有短板。而且它把动作离散化压缩，虽然省了 Token，但万一量化误差大，精细操作会不会翻车？总之，这是一次成功的“去中介化”尝试，但离真正的通用机器人还有距离，别把“自回归”当救命稻草，该补的视觉短板还得补。
—

研究动机Motivation

当前 VLA 领域的主流范式是“VLM-as-encoder”，即把预训练好的 VLM 仅作为特征编码器，将特征输入到独立的流匹配（Flow Matching）或扩散专家模型中生成动作 [3, 4, 5]。这种架构虽然提升了动作生成的平滑度和频率，却切断了 VLM 原生推理能力（如思维链 CoT、上下文学习）与动作生成的直接联系。VLM 的“思考”被压缩成中间特征，导致其无法直接指导动作，甚至引发“灾难性遗忘”，削弱了 VLM 的感知和语言理解能力 [17, 18]。此外，早期的自回归 VLA（如RT-2 [1]）因动作 Token 化效率低、高频控制慢而被放弃。G0.5 旨在解决这一矛盾：如何在保留 VLM 作为生成式决策者（Actor）的同时，解决自回归动作生成的效率瓶颈？它试图证明，通过高效的动作 Token 化和原生的思维链，自回归架构不仅能恢复 VLM 的推理能力，还能在长视界任务和零样本迁移上超越当前的“编码器+专家”范式。
—

方法Method

G0.5 的核心是一个统一的自回归 Transformer 架构，基于 Qwen3.5 2B 初始化，将感知、推理和动作整合在单一 Token 流中。整体 Pipeline 分为三个关键创新模块：首先是跨本体动作编解码器（Cross-embodiment ActionCodec）。不同于以往按维度分箱或固定 DCT 变换 [11]，该模块将不同机器人的动作分解为语义对齐的运动部件（如左臂、右臂、夹爪），利用残差向量量化（RVQ）和时序对比损失，将异构动作映射到统一的离散词汇表。这使得模型能根据当前激活的关节动态生成稀疏 Token，大幅降低解码负担。其次是原生思维链（Native CoT）。模型在生成动作前，可自发输出任务分解（Subtask）、物体定位（BBox）、运动轨迹（Trace）和动作提示（ActionHint）等推理 Token。这些推理 Token 与动作 Token 共享同一解码器和损失函数，使得推理成为动作生成的自然前置步骤，而非外挂模块。最后是视觉记忆模块。为应对长视界任务的非马尔可夫特性，模型在 Vision Transformer 中插入因子化时空注意力模块，融合多帧历史视觉信息，同时通过随机丢弃历史帧防止过拟合，确保在有限延迟下实现闭环控制。

实验Experiments

论文在 7 个独立场景下进行了全面评估。在 DROID 零样本迁移（环境/物体未见）中，G0.5 达到 82.5% 成功率，显著优于π0.5-DROID (57.5%) 和 MolmoAct2-DROID (52.0%) [4, 44]。在 R1-Lite/Pro 真实世界微调中，G0.5 以 76.7% 的胜率碾压π0.5 (53.3%) 和 GR00T-N1.7 (24.4%)。在 BEHAVIOR-1K 长视界挑战中，G0.5 以 31.4% 的得分超越冠军。消融实验显示，开启 CoT 和自回归解码（AR+CoT）在语言遵循率和任务成功率上均优于仅用动作解码或流匹配头。然而，实验也暴露了局限性：在低对比度视觉线索（如半透明抽屉）任务中，G0.5 表现不如基线，表明其对视觉特征依赖较强。此外，虽然推理速度（190ms）与流匹配相当，但高频控制下的 Token 生成开销仍需进一步优化。
