COMFYCLAW: Self-Evolving Skill Harnesses for Image Generation Workflows

Zongxia Li, Dawei Liu, Fuxiao Liu, Yuhang Zhou, Xiyang Wu, Jingxi Chen
abspdf

论文点评Review

这篇论文给 ComfyUI 加了个“自我进化”的脑壳，试图让 Agent 别光靠 Prompt 瞎蒙，而是把修图流程变成可复用的技能。COMFYCLAW 这名字听着像爪子，确实想抓牢 workflow 的命门。亮点在于它不满足于单次生成，而是搞了个技能进化库，把失败经验蒸馏成 Agent Skills，有点像 Voyager 在图像领域的翻版。但吐槽点也很明显：ComfyUI 本身就是个节点地狱，这框架虽然加了 typed graph editing 和 VLM verifier，但本质上还是在跟 Diffusion 模型的随机性搏斗。而且实验主要集中在静态图片，视频生成直接略过，毕竟视频节点更复杂，这“进化”可能跑不动。另外，技能库的验证依赖 held-out prompts，如果测试集分布偏移，技能会不会变脆？总之，是个不错的 Agent 工作流尝试，但离“通用具身”还差着物理世界的距离，更多是数字世界的“画饼”大师。
—

研究动机Motivation

现有 Agent 正从 Prompt 聊天转向工作流执行 [1, 2]，尤其在图像生成领域，Prompt 掩盖了太多决策细节（如 conditioning 方式、组件组合）[4, 5]。ComfyUI 暴露了这些决策，但也让 Agent 面临图编辑、约束满足和故障修复的复杂挑战 [3]。现有工作如 ComfyGen [4]、ComfyGPT [5] 多优化单次 Prompt 的生成，缺乏长期记忆。虽然 GEMS [18] 展示了闭环优化潜力，但其技能库是静态的，或仅被动存储经验而非主动提炼为可复用技能 [18]。这意味着一次成功的修复很难转化为未来安全调用的验证过程 [8]。Voyager [8] 虽通过自动课程和技能库实现自我改进，但主要面向开放环境。COMFYCLAW 旨在解决这一痛点：Agent 不仅要在单次运行中修复工作流，还需将反馈转化为长期可复用的控制知识。这需要两个组件：暴露工具/反馈的 Harness 和将经验转化为程序性知识的技能管理 [19-24]。缺乏进化技能会导致重复试错，缺乏强 Harness 则技能易脆 [25-30]。因此，核心问题是：自验证器的反馈能否同时支持即时修复和长期技能库进化？
—

方法Method

COMFYCLAW 框架将工作流构建视为技能增强的 MDP，包含三个核心模块。首先是 Workflow Construction Harness，将 ComfyUI 图编辑建模为有类型（typed）的图编辑序列。Agent 通过规划、构建、增强三个阶段操作 DAG，支持节点插入、参数调整、LoRA 加载等。技能检索采用渐进式披露（progressive disclosure），仅展示元数据，按需加载详情，控制上下文大小。其次是 Verifier-Guided Refinement，使用 VLM（如 Qwen3-VL-8B-Instruct）作为验证器。它将 Prompt 分解为可观测需求清单，返回通过/失败标签、整体细节分及局部失败描述。奖励函数结合需求通过率（60%）和细节分（40%）。验证器提供结构化反馈驱动迭代，直到分数达标或达到最大迭代次数。最后是 Skill Evolution，这是核心创新。系统收集成功/失败轨迹，按反馈和错误聚类。针对每个簇，Agent 提议技能突变（创建、修订、合并等）。突变需经过验证集测试（held-out prompts），仅当性能不下降时才提交到技能库。这确保了技能的可复用性和泛化性，而非过拟合单次任务。整个流程形成闭环：执行 -> 验证 -> 进化 -> 复用。

实验Experiments

实验在四个基准上评估：GenEval2（组合推理）、DPG-Bench（密集提示）、OneIG-EN/ZH（多语言/风格）。使用三种 Agent（Claude Sonnet 4.5, Qwen-3.6-35B, Gemma-4-E4B）和两个图像骨干（LongCat, Z-Image-Turbo）。基线为仅使用初始工具的 BASE 方法。指标包括 GenEval2 的 Soft-TIFA 几何平均、DPG 的算术平均及 OneIG 的 VQAScore。结果显示 COMFYCLAW 在所有配置下均优于 BASE，平均得分提升显著（如 Claude+LongCat 从 67.08 升至 75.52）。消融表明技能进化贡献了约 4 个绝对点的提升。人类评估（2400 张图）也显示偏好 COMFYCLAW。技能分析发现，进化技能占技能读取的 50%，且在 DPG/GenEval2 上依赖度更高。工作流编辑中仅 39% 为 Prompt 修改，其余涉及图拓扑、LoRA 选择等，证明优化不仅限于提示工程。局限性在于仅支持图像生成，视频工作流因计算和时序复杂性未涉及。
