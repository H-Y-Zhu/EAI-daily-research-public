STAR-VLM: Spatiotemporal Grounding Vision-Language Models for Motion and Velocity Estimation via Automotive Radar Supervision

Pou-Chun Kung, Aryaman Rao, Utkrisht Sahai, Hemanth Murali, Yi Liu, Rui-Yu Lin
abspdf

论文点评Review

这篇论文给 VLM 的“时空感知”强行加了个“雷达外挂”。作者发现现有 VLM 要么只会看静态图，要么靠昂贵的标注学运动，于是把车载雷达的 Doppler 信号当免费老师。这招确实聪明，毕竟雷达便宜又普及，比 LiDAR 香多了。但别高兴太早，它只能测径向速度，全速还得靠猜。而且这本质上还是 SFT，不是真正的“无监督”。不过能把 SegAnyMo 这种专用模型按在地上摩擦，说明雷达监督确实比纯视觉幻觉靠谱。就是不知道真车上雷达噪声大不大，模型能不能扛得住。此外，虽然提出了遮挡过滤，但雷达点云稀疏性带来的定位误差依然是个隐患，毕竟雷达不是激光雷达，精度没法比。
This paper forcibly adds a 'radar external module' to the VLM's 'spatiotemporal perception'. The authors found that existing VLMs either only view static images or learn motion through expensive annotations, so they treat the automotive radar's Doppler signal as a free teacher. This move is indeed clever, after all radar is cheap and widespread, much more favorable than LiDAR. But don't get too excited, it can only measure radial velocity, full velocity still relies on guessing. Moreover, this is essentially still SFT, not true 'unsupervised'. However, being able to beat specialized models like SegAnyMo soundly shows that radar supervision is indeed more reliable than pure visual hallucinations. Just don't know if radar noise is large on real cars, whether the model can withstand it. In addition, although occlusion filtering is proposed, the positioning error brought by radar point cloud sparsity remains a hidden danger, after all radar is not LiDAR, accuracy cannot be compared.

研究动机Motivation

具身智能需要理解动态场景，但现有 VLM 在时空推理上很弱。虽然 DepthLM [6] 解决了空间度量，但没解决时间维度（速度）。其他方法依赖人工标注 [3, 4] 或合成数据，成本高且有 sim-to-real gap。LiDAR 只能给空间深度，不能直接给运动状态。车载雷达成本低、部署广，天然提供 Doppler 测速，是理想的无标注监督源。作者想解决 VLM 缺乏物理度量（metric）时空理解的问题，特别是速度估计。现有工作如 DriveMLLM [11] 侧重空间，STSBench [13] 侧重场景，但都缺乏物理单位的速度推理。雷达作为补充模态，能直接提供运动线索，填补了 VLM 在物理世界动态理解上的空白。
Embodied AI needs to understand dynamic scenes, but existing VLMs are very weak in spatiotemporal reasoning. Although DepthLM [6] solved spatial metrics, it did not solve the time dimension (speed). Other methods rely on manual annotations [3, 4] or synthetic data, high cost and have sim-to-real gap. LiDAR can only provide spatial depth, cannot directly provide motion state. Automotive radar has low cost, wide deployment, naturally provides Doppler speed measurement, is an ideal unlabelled supervision source. The authors want to solve the problem of VLM lacking physical metric spatiotemporal understanding, especially speed estimation. Existing works like DriveMLLM [11] focus on space, STSBench [13] focus on scenes, but both lack physical unit speed reasoning. Radar as a supplementary modality can directly provide motion clues, filling the gap in VLM's dynamic understanding in the physical world.

方法Method

整体流程是：预处理雷达点云 -> 投影到图像 -> 构建 QA 对 -> SFT 训练 VLM。
1. 数据构建 (STAR-Bench): 用 nuScenes 数据，雷达点投影到图像。关键创新是**遮挡过滤** (Fig. 4)，防止雷达点穿透物体导致标签错误。具体逻辑是搜索最近邻，若深度差大于 0.3 米且像素距离小于 30，则视为遮挡移除。
2. Prompt 设计 (Fig. 5): 结合文本坐标 (x,y) 和视觉标记 (箭头)，比单纯坐标或单纯标记效果更好，增强像素级 grounding。模板固定为“该点具有运动状态 X”和“径向速度 Y m/s”。
3. 训练策略 (Fig. 6): 多任务联合训练。除了运动分类和径向速度，还加入**自车速度 (ego-velocity)** 监督。实验发现这能帮助模型区分自车运动和物体运动，提升精度。
4. 模型：基于 Qwen3-VL 进行 SFT，无架构修改。统一焦距以适配不同相机。
5. 核心逻辑：利用雷达 Doppler 作为 Ground Truth，让 VLM 学习物理运动规律，而非仅仅识别物体。
The overall process is: preprocess radar point cloud -> project to image -> build QA pairs -> SFT train VLM.
1. Data Construction (STAR-Bench): Use nuScenes data, radar points projected to image. Key innovation is **Occlusion Filtering** (Fig. 4), preventing radar points penetrating objects causing label errors. Specific logic is searching nearest neighbor, if depth diff > 0.3m and pixel dist < 30, then treated as occlusion and removed.
2. Prompt Design (Fig. 5): Combine text coordinates (x,y) and visual markers (arrows), better effect than pure coordinates or pure markers, enhance pixel-level grounding. Template fixed as "This point has motion state X" and "Radial velocity Y m/s".
3. Training Strategy (Fig. 6): Multi-task joint training. Besides motion classification and radial velocity, also add **ego-velocity** supervision. Experiments found this helps model distinguish ego motion and object motion, improve accuracy.
4. Model: Based on Qwen3-VL for SFT, no architecture modification. Unified focal length to adapt to different cameras.
5. Core Logic: Use radar Doppler as Ground Truth, let VLM learn physical motion laws, not just identify objects.

实验Experiments

数据集：STAR-Bench (nuScenes) 和 TADBench。基线包括开源 VLM (Qwen2.5/3-VL)、物理 VLM (Cosmos-Reason)、度量深度 VLM (DepthLM) 及专用模型 (SegAnyMo, Any4D)。指标：运动分类准确率、径向速度 MAE。结果：STAR-VLM 在两项任务上均 SOTA，优于专用模型 (Fig. 7, 8)。消融实验 (Table II) 显示加入 ego-velocity 监督显著提升联合任务性能。相比 Any4D 的密集光流，STAR-VLM 在查询点精度上更准。相比 SegAnyMo 的分割，STAR-VLM 在运动状态分类上更稳。证明了雷达监督的有效性。此外，在 TADBench 上，即使没有像素坐标提示，模型也能保持良好性能，泛化性较强。
Datasets: STAR-Bench (nuScenes) and TADBench. Baselines include open-source VLM (Qwen2.5/3-VL), physical VLM (Cosmos-Reason), metric depth VLM (DepthLM) and specialized models (SegAnyMo, Any4D). Metrics: Motion classification accuracy, Radial velocity MAE. Results: STAR-VLM is SOTA on both tasks, better than specialized models (Fig. 7, 8). Ablation experiments (Table II) show adding ego-velocity supervision significantly improves joint task performance. Compared to Any4D's dense optical flow, STAR-VLM is more accurate on query point accuracy. Compared to SegAnyMo's segmentation, STAR-VLM is more stable on motion state classification. Proves the effectiveness of radar supervision. In addition, on TADBench, even without pixel coordinate prompts, model can maintain good performance, generalization is strong.
