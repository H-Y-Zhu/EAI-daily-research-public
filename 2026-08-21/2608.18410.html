Role-Conditioned Sub-Token Routing for Efficient Vision-Language-Action Policies

Wei Jiang, Wei Wang
abspdf

论文点评Review

这篇论文给 VLA 模型做了个“微创手术”，试图在保留 token 位置的同时压缩值向量宽度，把 KV 缓存压到了原来的 9%-11%。这招比单纯剪枝聪明，毕竟剪枝是“一刀切”，信息全丢；子令牌路由是“精修”，保留关键维度。不过，作者也没藏着掖着，承认了潜在角色表示不可解释，而且视觉和语言压缩之间存在耦合效应，目前还没优化好。最尴尬的是，他们测的是 KV 大小，没测实际推理延迟，毕竟稀疏计算实现起来未必快，可能只是“纸面效率”。总的来说，在 LIBERO 上效果不错，尤其是长视界任务，但“黑盒”路由和跨模态耦合仍是隐患，属于理论可行但工程落地还需验证的类型，别指望能直接省掉显卡预算。
This paper performs a "minimally invasive surgery" on VLA models, attempting to compress value vector width while retaining token positions, compressing the KV cache to 9%-11% of the original. This approach is smarter than simple pruning, as pruning is a "one-size-fits-all" cut where all information is lost; sub-token routing is "refinement", retaining key dimensions. However, the authors did not hide anything, admitting that potential role representations are uninterpretable, and there is a coupling effect between vision and language compression that is not yet optimized. The most awkward part is they measured KV size, not actual inference latency, as sparse computation implementation isn't necessarily fast, possibly just "paper efficiency". Overall, performance is good on LIBERO, especially long-horizon tasks, but "black box" routing and cross-modal coupling remain hazards, belonging to the type that is theoretically feasible but requires engineering validation, do not expect to directly save GPU budget.

研究动机Motivation

VLA 模型推理成本高，主要因为视觉 token 序列长。现有加速方法如 VLA-ADP (Pei et al., 2025) 和 VLA-Pruner (Liu et al., 2025) 主要做 token 级剪枝，但这会导致信息丢失，尤其在闭环控制中误差会传播，导致策略崩溃。Sub-token routing (Jiang and Wang, 2026) 提供了压缩值宽度的替代方案，但直接应用到 VLA 效果差，因为感知、语言和控制信息分布不均。固定分解会移除重要维度。因此需要一种能根据控制目标学习路由结构的方法，而不是预设语义角色。本文旨在解决如何在保持 token 数量的同时，自适应地压缩每个 token 内的价值表示，以平衡压缩率和性能，避免激进剪枝导致的策略崩溃，为高效 VLA 提供新路径。
VLA model inference costs are high, mainly due to long visual token sequences. Existing acceleration methods such as VLA-ADP (Pei et al., 2025) and VLA-Pruner (Liu et al., 2025) mainly perform token-level pruning, but this leads to information loss, especially in closed-loop control where errors propagate, causing policy collapse. Sub-token routing (Jiang and Wang, 2026) offers an alternative for compressing value width, but direct application to VLA performs poorly because perception, language, and control information distributions are uneven. Fixed decomposition removes important dimensions. Therefore, a method is needed that can learn routing structures based on control goals, rather than preset semantic roles. This paper aims to solve how to adaptively compress value representations within each token while maintaining token count, to balance compression rate and performance, avoid policy collapse caused by aggressive pruning, and provide a new path for efficient VLA.

方法Method

整体流程分两步：先可选地做 token 级剪枝，再对保留的 token 做子令牌路由。核心创新在于 RoleSub 模块。首先，通过固定正交矩阵 R 将值向量变换到正交路由空间，这保证了变换无损，只是基变换。接着，将变换后的值向量分成 S 组（如 16 组）。路由决策由三部分信号决定：当前 token 隐藏状态、轻量级角色估计器生成的潜在角色表示、以及语言上下文。这三个信号加权求和得到路由分数，Top-K 选择保留的组。此外，针对不同 token 类型（视觉、语言等）分配独立的值预算，并通过潜在角色优先级动态分配每个 token 的组数。训练时冻结主干，联合训练 LoRA 和路由头，通过动作预测损失优化。这种设计让模型学会在有限容量下如何分配价值信息，而不依赖预定义的语义角色，实现了更细粒度的控制，但增加了训练复杂度。
The overall process is divided into two steps: first optionally perform token-level pruning, then perform sub-token routing on retained tokens. The core innovation lies in the RoleSub module. First, transform value vectors to an orthogonal routing space via a fixed orthogonal matrix R, which guarantees lossless transformation, merely a basis change. Next, split the transformed value vectors into S groups (e.g., 16 groups). Routing decisions are determined by three parts of signals: current token hidden state, latent role representation generated by a lightweight role estimator, and language context. These three signals are weighted and summed to obtain routing scores, with Top-K selecting retained groups. Additionally, independent value budgets are allocated for different token types (vision, language, etc.), and the number of groups for each token is dynamically allocated via latent role priority. During training, the backbone is frozen, LoRA and routing head are jointly trained, optimized via action prediction loss. This design allows the model to learn how to allocate value information under limited capacity without relying on predefined semantic roles, achieving finer-grained control, but increases training complexity.

实验Experiments

在 OpenVLA-OFT-7B 和四个 LIBERO 套件上评估。基线包括无压缩、训练-free 剪枝、训练过的 token-only 剪枝、以及普通子令牌路由。指标是闭环任务成功率。结果显示，在匹配视觉 KV 预算下，RoleSub 在 36 种设置中有 33 种优于 token-only 剪枝，尤其在激进压缩和长视界任务上增益明显。语言压缩实验发现，语言 token 位置关键，不能剪，但值宽度可压缩至 1/16 几乎无损失。结合视觉和语言压缩后，总 KV 降至 9.2%-11.3%。但 LIBERO-10 对联合压缩敏感，表明视觉和语言预算存在耦合，需更多语言值预算补偿视觉压缩带来的信息损失，揭示了多模态压缩的复杂性，单纯压缩某一模态可能不够。
Evaluated on OpenVLA-OFT-7B and four LIBERO suites. Baselines include no compression, training-free pruning, trained token-only pruning, and ordinary sub-token routing. The metric is closed-loop task success rate. Results show that under matched visual KV budget, RoleSub outperforms token-only pruning in 33 out of 36 settings, especially with significant gains in aggressive compression and long-horizon tasks. Language compression experiments found that language token positions are critical and cannot be pruned, but value width can be compressed to 1/16 with almost no loss. After combining vision and language compression, total KV drops to 9.2%-11.3%. However, LIBERO-10 is sensitive to joint compression, indicating coupling between vision and language budgets, requiring more language value budget to compensate for information loss caused by vision compression, revealing the complexity of multimodal compression, where simply compressing one modality may not be enough.
