Narrative World Model: Narratology-Grounded Writer Memory for Long-Form Fiction

Mohammad Saifullah, Thomas Kornmaier, Taaha Kazi, Vasu Sharma, Aditya Sanjiv Kanade, Aanand Kumar Yadav
abspdf

论文点评Review

这篇论文给“世界模型”贴了个“叙事”标签，听起来高大上，实则是在搞长篇小说的“记忆管理”。作者很懂行，没直接测生成质量，而是用固定读者 Opus 4.8 隔离生成能力，专测“记忆检索”，这招挺狠。不过，Embodied AI 同行看了估计会笑：这跟机器人有啥关系？顶多算个文本世界的模拟器。好在实验设计严谨，对比了 Graphiti 这种强基线，证明了结构比图大小重要。特别是他们做了提取器公平性控制，排除了模型质量干扰。就是应用场景太窄，仅限于文学创作，离具身智能还差着十万八千里，但作为长文本记忆基准，确实有点东西，值得文本生成领域关注。

研究动机Motivation

长篇小说生成面临“局部流畅但全局崩塌”的困境。现有 RAG 系统 (Lewis et al., 2020) 只能检索文本片段，无法回答“谁在何时知道秘密”这类多跳叙事问题。通用知识图谱 (Graphiti, Rasmussen et al., 2025) 缺乏叙事学结构，无法区分事件顺序与揭示顺序。作者指出，作家需要的是“章节安全”的证据，而非通用事实。现有系统在处理 epistemic state（认知状态）和 dramatic function（戏剧功能）时失效，导致多跳推理失败，无法支持跨章节的因果推理。例如，无法判断某个秘密在特定章节是否已被角色知晓，这直接影响了后续情节的连贯性。
—

方法Method

NWM 包含发布、图谱、检索、验证四步。首先，Publish 阶段用提取器将章节转为 typed memory records，包含 focalization、epistemic state 等叙事字段，如人物状态、关系变化、承诺状态。其次，构建 Temporal Knowledge Graph，边带有 validity interval，记录状态随章节的变化，确保因果截断。第三，Query-Conditioned Hybrid Retrieval 结合 BM25 和向量检索，并扩展 1-hop 图邻域，确保只检索当前章节前的证据。最后，RLM QA 进行递归验证。核心创新在于将叙事学概念（如 promise/payoff）作为图结构的一等公民，而非通用实体关系，实现了叙事结构的显式建模。这种设计使得系统能区分“事件发生”与“读者得知”的时间差，解决了传统图谱无法捕捉的叙事逻辑漏洞。
—

实验Experiments

在私有和公共语料上测试，使用 176 题多跳基准。基线包括 Simple Search, RAG, GraphRAG, Graphiti。指标为 QA 准确率。NWM Graph Retrieval 在私有集达 0.898，Graphiti 仅 0.574。消融显示，即使 Graphiti 用 NWM 的提取器，性能仍低，证明优势来自表征而非提取。图大小对比显示 NWM 图更小但效果更好，证实叙事结构是关键。统计检验显示差异显著 (p < 10^-5)，且 Graphiti 在 NWM 答对题上几乎全 abstain，说明其缺乏对应表征。公共集结果也复现了排序，验证了泛化能力。
