DWM: Separating World Effects from Actions in Latent World Models

Yi-Ge Zhang, Tianqi Du, Qi Zhang, Yisen Wang
abspdf

论文点评Review

这篇论文终于有人敢把“重力”从“推箱子”里分出来了。传统 latent world model 就像个糊涂账，把 agent 的主动操作和环境自发的漂移混在一起预测，遇到重力、惯性这种“不管你怎么动它都动”的情况就崩。DWM 这招挺聪明，训练时多开一个“世界头”专门负责那些跟动作无关的惯性，推理时又切回单头，既没增加部署成本，又解决了物理一致性幻觉。不过，这方法本质上还是靠 loss 硬掰，如果世界效应太复杂（比如流体），光靠正交约束够吗？另外，W-variant 的构造有点“为了实验而实验”，真实机器人场景里这种恒定漂移可不多见。但无论如何，给 latent space 做减法（解耦）是个好方向，至少比盲目堆参数强。
—

研究动机Motivation

现有基于动作条件的 latent world models（如 LeWM [Maes et al., 2026]）通常将下一个潜在状态视为单一目标进行监督。这种 monolithic 的监督信号迫使模型将 agent 动作引起的状态变化与环境固有的动力学（如重力、惯性）混同学习。在静态或平坦基准（如标准 PushT）中，这种混淆尚可容忍，因为物体运动主要响应 agent。但在真实物理环境中，存在 action-invariant 的世界效应（world effect），即即使 agent 不操作，环境状态也会因重力或漂移而改变。现有方法无法区分这两者，导致多步 rollout 误差累积，planner（如 CEM）基于错误预测选择动作。Hafner et al. (2019, 2021) 虽奠定了 latent planning 基础，但未显式建模环境自演化。因此，研究如何解耦动作效应与世界效应，对于提升具身智能在复杂物理环境下的规划鲁棒性至关重要。
—

方法Method

DWM 框架在保持原有 backbone（Encoder phi, Predictor g）不变的前提下，通过训练时的辅助分支实现解耦。整体 Pipeline 分为训练与推理两阶段：推理时仅使用原有的 pred head hp 输出 z_hat，保证部署兼容性；训练时增加一个并行的 world head hw。核心创新在于两个辅助 Loss：1) World-Contrastive Loss (L_wc)：利用 InfoNCE 目标，对同一状态的不同动作扰动（at vs a_tilde）进行对比，强制 hw 的输出 z_w 对动作不变，仅捕捉环境自演化部分；2) Orthogonality Constraint (L_orth)：计算 z_w 与残差动作分量 z_a = z_hat - z_w 的余弦相似度，强制两者正交，确保动作信息不被 hw 吸收。最终总 Loss 为 L = L_WM + lambda_wc*L_wc + lambda_orth*L_orth。这种设计将显式加法分解 z_hat = z_w + z_a 引入监督信号，使模型学会区分“世界想怎么动”和“我想怎么动”，而无需修改底层架构。
—

实验Experiments

实验构建了 PushT-W, Reacher-W, TwoRoom-W 三个带持续世界效应的变体（重力滑动、垂直面重力、环境漂移），并保留原始平坦版本作为对照，另加 Ball-in-Cup 测试状态依赖动力学。基线为 LeWM。评测指标包括 CEM 规划成功率、预测误差（Offline/Rollout@20）及解耦诊断。结果显示，DWM 在 W-variant 任务上 CEM 成功率平均提升 13.1%（PushT-W +12.0%, Reacher-W +10.7%, TwoRoom-W +16.7%），且在原始平坦任务上性能持平。多步 rollout 误差显著降低（PushT-W 降低 66.7%）。消融实验表明 L_wc 和 L_orth 均必要。OOD 重力测试显示动作分量具有泛化性。这证明了显式解耦能提升物理一致性，但 W-variant 的构造可能限制了结论的普适性。
