Is Your LLM Secretly a World Model of the Internet? Model-Based Planning for Web Agents

Yu Gu, Boyuan Zheng, Boyu Gou, Kai Zhang, Cheng Chang, Sanjari Srivastava
abspdf

论文点评Review

这篇论文标题起得挺妙，“秘密世界模型”听着像玄学，其实是在挖掘 LLM 的隐式知识。作者精准抓住了 Web Agent 的痛点：真实网页存在大量不可逆操作，导致依赖回溯的传统 Tree Search 在沙盒外基本废了。WEBDREAMER 用 LLM 做模拟器，虽然听起来像是“用魔法打败魔法”，但效率提升确实实在。不过，Dreamer-7B 在 Reddit 这种密集文本页表现一般，说明世界模型对视觉密集场景的泛化还有坑。总的来说，这是一次把“规划”从“试错”变成“脑补”的务实尝试，虽然“脑补”偶尔会出错，但比真刀真枪砍效率高多了。它证明了专用世界模型在复杂 Web 环境中具备替代通用大模型进行高效规划的潜力，为后续研究奠定了坚实基础。
—

研究动机Motivation

现有 Web Agent 主要分两类：Reactive 和 Tree Search。Reactive 缺乏长远规划，容易短视 (Yao et al., 2023b)。Tree Search 虽然能规划，但依赖真实交互，在真实网页上存在不可逆操作（如下单、改隐私设置），导致回溯（backtracking）几乎不可行 (Koh et al., 2024b)。此外，Tree Search 推理延迟高，影响用户体验。因此，需要一种能模拟环境动态而不消耗真实交互的规划方法，即 Model-Based Planning。互联网环境开放且动态变化，构建有效的世界模型极具挑战，但 LLM 预训练数据中隐含了网页结构知识，这为利用 LLM 模拟 Web 环境提供了可能。
—

方法Method

核心是 WEBDREAMER 框架。流程：1. 候选动作生成与自优化；2. 模拟阶段 (sim)：用 LLM 预测动作后的状态变化（自然语言描述）；3. 评分阶段 (score)：用 LLM 评估模拟轨迹的完成度；4. 执行最优动作。训练方面，构建了 3.1M 合成数据集：通过 Web Random Walking 采集交互，用 Qwen2-VL-72B 生成状态变化描述，微调 Qwen2-VL-7B 得到 Dreamer-7B。Sim 模块预测状态转移，Score 模块打分，两者结合实现 Model Predictive Control。具体而言，Sim 包含状态变化预测和动作想象两个模块，生成轨迹长度 H。Score 采用三尺度响应（完成、进行中、错误）。数据合成通过随机浏览网页，捕捉动作前后截图，由大模型生成文本描述，过滤失败交互后训练。此外，候选动作生成采用两阶段采样与自优化，减少无关动作干扰。
—

实验Experiments

在 VisualWebArena, Online-Mind2Web, Mind2Web-Live 测试。基线为 Reactive 和 Tree Search。指标为成功率 (Success Rate) 和耗时。WEBDREAMER (GPT-4o) 在 VWA 上比 Reactive 提升 34.1%，效率比 Tree Search 高 4-5 倍。Dreamer-7B 在在线基准上接近 GPT-4o。消融实验表明模拟阶段比单纯重排动作更重要。规划 horizon 设为 1 效果最好，更长会导致幻觉累积。此外，在特定领域（如 Classifieds）进行域内微调后，Dreamer-7B 甚至超越 GPT-4o，证明了专用世界模型的潜力。在 VWA 沙盒环境中，Tree Search 虽可行但成本高，而 WEBDREAMER 在真实网站上的表现更稳健。
