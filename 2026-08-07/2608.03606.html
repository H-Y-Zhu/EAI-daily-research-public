Learning Clinical-Trial Strategy: Offline Policy Training for Decision Agents

William Bolton, Philip Torr
abspdf

论文点评Review

这篇论文把临床药物开发策略建模为离线决策问题，挺有意思，但离“具身”实在有点远。作者用 881 个历史决策片段训练模型，试图预测下一个 6 个月的试验组合。RW-BC 效果最好，甚至吊打 GPT-5.4 等前沿 Agent，这点值得点赞。不过，奖励信号是事后关联而非因果，模型可能只是记住了历史模式而非真正“学会”了策略。而且未来数据划分太小（n=24），结果虽显著但样本量让人捏把汗。总的来说，是个漂亮的离线 RL 实验，但别指望它能直接指导新药研发，毕竟真实世界比 JSON Schema 复杂多了，且存在未观测的混杂因素，模型输出的“策略”更多是历史行为的统计拟合。

研究动机Motivation

临床开发本质是不确定性下的序列决策，但现有 ML 工作多关注预定义试验是否成功或患者匹配 (Fu et al., 2022; Jin et al., 2024)，忽略了上游策略规划。赞助商需结合历史试验、监管信号、竞争态势等制定组合，但后果滞后且信息不完备。本文旨在解决“给定当前状态，下一步该 launch 哪些试验”的问题。现有 LLM Agent 虽能检索工具，但缺乏从历史决策轨迹中学习策略的能力，容易依赖预训练知识而非特定领域经验，难以应对时间切片后的新决策。此外，大多数工作未考虑决策的延迟后果，而本文通过离线奖励归因尝试捕捉长期影响。
—

方法Method

整体流程是将肿瘤药物开发转化为离线决策任务。首先构建时序数据集，整合 ClinicalTrials.gov、FDA 审查、SEC filings 等 5 类公开数据，形成 881 个 (s, a, R) 三元组。状态包含决策时点前的所有可用信息，动作定义为 14 字段的 JSON 试验组合，奖励基于 FDA 批准和营收归因。训练阶段对比四种目标：Behavioral Cloning (BC) 直接模仿；Reward-Weighted BC (RW-BC) 按试验回报加权采样，公式包含 pivotal 批准奖励、营收归因及失败惩罚；Learned- Reward BC (LR-BC) 学习奖励函数；Implicit Q-Learning (IQL) 基于价值函数估计优势。骨干模型为 Qwen-2.5-7B-Instruct + QLoRA，解码时强制 JSON Schema 约束，确保输出结构化。奖励计算考虑了试验是否 pivotal 及失败惩罚，IQL 则通过 expectile regression 估计状态价值，利用优势函数加权样本，使模型偏向优于平均水平的决策而非单纯模仿高回报窗口。IQL 使用 expectile tau=0.7 追踪上分位数，折扣因子 gamma=0.95，确保长期回报评估。

实验Experiments

实验在 8 个 held-out 评估集上进行，包括单药、赞助商、药物类别及时间切分，重点考察后 August 2025 的无污染集。基线包括 GPT-5.4、Claude Opus 4.5 等工具 Agent 及随机策略。指标含 Indication F1、Strict F1 等。结果显示，离线训练模型显著优于未微调基线，RW-BC 在严格 F1 上达 14.2%，远超 Agent 的 2.1%。自回归评估表明微调模型对误差更鲁棒。消融显示奖励加权比单纯模仿更能捕捉成功设计。尽管未来数据划分样本较小，但统计显著性支持了离线学习在策略规划上的有效性。此外，RW-BC 在成功试验设计上匹配率更高，证明了奖励信号的有效性。
