Scalable Behaviour Cloning on Browser Using via Skill Distillation

Kaisen Yang, Zheng Jiang, Yuzhao Peng, Houde Qian, Boshi Zhang, Youjie Zheng
abspdf

论文点评Review

这篇论文给浏览器 Agent 开了个“技能包”外挂，核心观点挺对：Agent 不是手残，是脑子缺常识。把人类浏览记录洗成自然语言技能卡，比直接模仿点击靠谱多了。不过，技能库怎么维护？会不会越滚越大变成垃圾堆？作者搞了个技能图来压缩，但检索策略还是靠语义相似度，有点偷懒。实验数据看着挺美，WebArena 涨了 20%，但 ClawBench 这种真实网站波动大的地方，技能真的能扛住 DOM 变化吗？感觉是“用魔法打败魔法”，把动作序列变成了文本描述，本质还是靠大模型推理，算不算真正的具身智能进步？反正比纯 RL 省算力，适合不想训练大模型的小厂。
—

研究动机Motivation

浏览器 Agent 的瓶颈不在操作，而在信息不全时的决策。现有工作如 Mind2Web (Deng et al., 2023) 和 WebArena (Zhou et al., 2024) 虽然提供了环境，但 Agent 仍依赖 trial-and-error，因为缺乏决策先验。人类浏览轨迹包含隐性知识，但直接克隆 raw traces 太脆，依赖 DOM 坐标和页面状态，换个网站就废。WebLINX (Lù et al., 2024) 收集了轨迹，但没解决泛化问题。本文认为可复用单元不是动作也不是轨迹，而是自然语言技能。
—

方法Method

BrowserBC 框架分四步。1. 行为证据抽象：清洗轨迹，过滤噪音，提取任务相关证据单元。2. 程序技能蒸馏：用 LLM 把证据转成结构化技能卡（意图、步骤、恢复策略等），剥离坐标等易变信息。3. 技能库构建：合并相似技能，建技能图（Skill Graph）防止冗余。4. 技能条件执行：推理时检索相关技能作为上下文，Agent 结合当前页面状态执行。核心创新是技能与执行解耦，蒸馏一次可被不同模型复用。技能卡包含意图、适用条件、步骤、里程碑、终止证据和恢复策略，确保可审计和更新。技能图通过节点和边组织技能，支持增量更新和局部检索，避免库膨胀。
—

实验Experiments

在 WebArena-Hard, ClawBench, OSWorld 上测试。基线是 Base Agent (Skill-Off)。指标是成功率 (SR) 和步数。WebArena-Hard 成功率从 60.5% 升到 81.4%。ClawBench 从 32.9% 升到 68.4%。消融实验显示技能能减少交互步数，且蒸馏器和执行器解耦有效（Sonnet 蒸馏的技能 Qwen 执行也能用）。OSWorld 案例证明技能能迁移到桌面环境，解决路径绑定问题。
