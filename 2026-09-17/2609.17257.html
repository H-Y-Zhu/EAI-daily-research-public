Exploring 2D backbone effects for indoor semantic occupancy prediction

Shizhang Fanga, Wanling Yea, Qi Zheng
abspdf

论文点评Review

这篇论文给 RGB-D 感知领域一记响亮的耳光。大家都在卷 3D 解码器、搞多模态融合，把 2D 骨干网当成随便插拔的“默认插件”，结果发现换个大模型比改架构还管用。DINOv2 直接干翻 DROcc，CLIP-ResNet 却原地踏步。这告诉我们：别总想着在下游修修补补，上游特征没学好，下游再努力也是白搭。不过，长尾类别还是难搞，有些结构就是看不见，光靠换 backbone 也救不了命。实验设计极其克制，只换编码器，其他全锁死，这种“控制变量”的狠劲，比那些花里胡哨的架构改进更让人信服。这简直是给那些过度设计 3D 模块的研究者泼了盆冷水。
This paper delivers a stinging slap to the RGB-D perception field. Everyone is competing on 3D decoders and multimodal fusion, treating 2D backbones as interchangeable "default plugins", only to discover that swapping in a larger model proves more effective than modifying the architecture. DINOv2 directly surpasses DROcc, whereas CLIP-ResNet remains stagnant. This indicates: do not always focus on patching downstream; if upstream features are not learned well, further effort downstream is futile. However, long-tail categories remain challenging; some structures remain invisible, and simply swapping backbones cannot resolve the issue. The experimental design is extremely restrained, changing only the encoder while locking all other components; this rigor of "controlling variables" is more convincing than those flashy architectural improvements. This is simply pouring cold water on researchers who over-design 3D modules.

研究动机Motivation

具身智能需要 voxel 级的语义理解，但现有研究多聚焦于视图变换或 3D 优化（如 TPVFormer [2], VoxFormer [3]）。在 EmbodiedScan [6] 等基准中，2D 骨干网常被默认为次要工程细节。然而，体素特征是通过投影采样 2D 特征得到的，如果 2D 特征的空间对齐或类别可分性差，3D 融合无法恢复丢失的信息。不同预训练目标（CLIP, DINOv2）的空间行为差异巨大，但缺乏受控对比。本文旨在验证 2D 表示是否限制了体素级语义证据的质量，挑战了“骨干网无关”的假设，强调视觉表征在 3D 提升前的决定性作用。
Embodied intelligence requires voxel-level semantic understanding, yet existing research predominantly focuses on view transformation or 3D optimization (e.g., TPVFormer [2], VoxFormer [3]). In benchmarks such as EmbodiedScan [6], 2D backbones are often treated as secondary engineering details. However, voxel features are derived by projecting and sampling 2D features; if the spatial alignment or class separability of 2D features is poor, 3D fusion cannot recover the lost information. Different pretraining objectives (CLIP, DINOv2) exhibit significant differences in spatial behavior, yet lack controlled comparison. This paper aims to verify whether 2D representations constrain the quality of voxel-level semantic evidence, challenging the "backbone-agnostic" assumption and emphasizing the decisive role of visual representation before 3D enhancement.

方法Method

整体采用 EmbodiedScan 风格的固定 RGB-D 占用预测管线。数据流为：多视角 RGB-D 输入 -> 2D 骨干网提取特征 + FPN -> 体素中心投影到 2D 图采样 -> 深度分支体素化 -> 特征拼接 -> 3D Neck -> 占用头。核心创新在于“控制变量法”：固定深度分支、体素投影、融合 neck、损失函数及训练策略，仅替换 2D 图像编码器（phi）。具体包括 CLIP-ResNet、CLIP-ViT、BLIP2 和 DINOv2。所有变体适配 FPN 兼容接口，Transformer 的 patch tokens 被重排为空间图。投影过程使用双线性采样，不引入额外遮挡推理，确保差异仅源于视觉表示的 3D 提升能力。深度分支使用 Minkowski ResNet-34，最终特征拼接后送入 3D 解码器。
Overall, it adopts an EmbodiedScan-style fixed RGB-D occupancy prediction pipeline. The data flow is: multi-view RGB-D input -> 2D backbone feature extraction + FPN -> voxel center projection to 2D map sampling -> depth branch voxelization -> feature concatenation -> 3D Neck -> occupancy head. The core innovation lies in the "control variable method": fixing the depth branch, voxel projection, fusion neck, loss function, and training strategy, while only replacing the 2D image encoder (phi). Specifically, this includes CLIP-ResNet, CLIP-ViT, BLIP2, and DINOv2. All variants adapt to FPN-compatible interfaces, with Transformer patch tokens rearranged into spatial maps. The projection process employs bilinear sampling, introducing no additional occlusion reasoning, ensuring differences arise solely from the 3D enhancement capability of visual representations. The depth branch utilizes Minkowski ResNet-34, and after final feature concatenation, it is fed into the 3D decoder.

实验Experiments

在 EmbodiedScan [6] 基准测试，40x40x16 网格，80 类语义。基线包括 EmbodiedScan 原版、复现版及 DROcc [17]。指标为 mIoU 及类别 IoU。结果显示，仅换 backbone 即可超越任务专用架构：DINOv2 达 30.55%，BLIP2 为 29.49%，显著优于 CLIP-ResNet 的 17.41%。DINOv2 在布局结构类表现强，BLIP2 在物体类接近。长尾分析显示，虽然强 backbone 改善了罕见物体，但屋顶、横梁等极难类别仍接近零。资源方面，BLIP2 参数量最大，DINOv2 平衡较好。
Evaluated on the EmbodiedScan [6] benchmark, 40x40x16 grid, 80 semantic classes. Baselines include EmbodiedScan original, reproduced version, and DROcc [17]. Metrics are mIoU and class IoU. Results show that simply changing the backbone can surpass task-specific architectures: DINOv2 reaches 30.55%, BLIP2 is 29.49%, significantly outperforming CLIP-ResNet's 17.41%. DINOv2 performs strongly on layout structure classes, while BLIP2 is comparable on object classes. Long-tail analysis indicates that although strong backbones improve rare objects, extremely difficult categories such as roofs and beams remain near zero. Regarding resources, BLIP2 has the largest parameter count, while DINOv2 is better balanced.
