From Traces to Agentic Worlds: Agentic Language World Models for Interactive Environment Simulation

Quanyu Long, Xiao Chen, Jianda Chen, Haozhen Zhang, Qisheng Hu, Jianzhu Bao
abspdf

论文点评Review

这个工作把“世界模型”玩出了新花样，不再死磕重建可执行代码，而是搞了个“世界书”（Worldbook）。说白了，就是让LLM当环境，但给它一本从历史轨迹里扒出来的“小抄”。这招挺聪明，省了逆向工程的苦，但本质上还是LLM在猜，不是真代码。虽然号称“无学习框架”，但构建世界书本身还得靠大模型，算不算“用大模型模拟大模型”？长期一致性提升明显，但 fidelity 终究受限于轨迹质量，有点“巧妇难为无米之炊”的意思。不过，它确实解决了长程状态丢失的痛点，让模拟环境能像真的一样“记住”之前的操作后果，比单纯 Prompt 强多了，算是给 Agent 训练省了笔大钱。
—

研究动机Motivation

训练 Agent 需要真实环境，但很多系统代码不可得。现有语言世界模型（LWMs）（Li et al., 2026）通常把历史和环境描述扁平化塞进 Prompt，导致长程状态丢失，比如删了文件后面再查会报错，但 Prompt 里可能没体现。Terminal-Universe（Wu et al., 2026）试图从轨迹重建可执行终端，但复杂环境往往缺少实现细节，轨迹无法完全还原系统依赖。我们需要一种不依赖原系统代码，仅凭交互轨迹就能恢复环境行为规范的方法，让模拟环境能像真的一样“记住”之前的操作后果，支持多轮交互而不崩塌，避免 Agent 在幻觉中自嗨。
—

方法Method

Trace2Env 分离线和在线两阶段。离线时，从历史轨迹构建“世界书”，包含 Schema（动作接口）、Grounded Evidence（具体观测）和 Induced Abstractions（归纳规则）。在线模拟时，世界模型 Agent 主动查询世界书，结合当前 Episode 状态和记忆，提出状态变更和观测。关键创新在于分离了“通用环境知识”（世界书，不可变）和“当前回合状态”（可变）。引入 Applicability Gate 判断检索证据是否适用，Validation Gate 确保状态变更符合 Schema 约束。这种架构让模拟环境能跨回合保持状态一致性，而不是每次只预测下一个观测，实现了状态与知识的解耦。此外，Harness 负责验证提议，确保状态更新合法，只有被接受的状态变更才会提交，保证了模拟的严谨性。这种设计允许同一个世界书支持多个模拟回合，同时每个回合保留自己的交互历史后果，避免了传统 Prompt 方法中状态被覆盖的问题，让模拟更像真人在玩。
—

实验Experiments

在 Terminal、SWE、Android 等 9 个环境测试。指标包括 AgentWorldBench 的五维评分（格式、事实性等）和长程交互一致性（W2R/Real）。结果显示 Trace2Env 在各项指标上均优于 Direct Prompting 和 Trace RAG。特别是在 ALFWorld 中，W2R 从 0.032 提升至 0.914，说明模拟动作在真实环境回放时更可靠。消融实验表明，世界书中的证据和抽象规则互补，增加构建轨迹数量能提升预测质量，但成本也随之增加。平均分从 69.51 提升到 75.94，证明了世界书加运行时机制的有效性。此外，在未见任务上也有显著增益，说明泛化能力不错，但构建成本随轨迹数线性增长，实际部署需权衡。
