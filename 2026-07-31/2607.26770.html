Vision-TL-Action: Neuro-Symbolic Trajectory Generation from Visual Observations and Temporal Logic

Zezhi Liu, Zhiwei Zheng, Hanqian Luo, Deyun Qin, Shizhen Wu, Yongchun Fang
abspdf

论文点评Review

这篇论文试图用视觉替代时序逻辑规划中的“上帝视角”几何信息，算是给 TeLoGraF 加了个视觉滤镜。虽然提出了神经符号融合，但本质上还是靠采样覆盖来刷成功率，单条轨迹性能其实不如已知状态基线。训练时用了特权信息（物体投影），推理时却号称端到端，有点“训练时作弊，推理时硬撑”的嫌疑。不过，在候选集够大时能追平甚至反超，说明视觉特征确实承载了足够的语义，只是单样本生成能力还需提升。这种“以量取胜”的策略在仿真中有效，但落地到真实机器人时，采样成本和时间约束可能是个大坑。
—

研究动机Motivation

现有时序逻辑（TL）规划器如 TeLoGraF (Meng and Fan 2025) 依赖精确物体几何，绕过了感知到符号的绑定，这在真实视觉场景中不可行。而 VLA 模型（如 RT-2, Brohan et al. 2023）虽能处理视觉指令，却缺乏显式的 STL 约束，难以保证任务的安全性和时序逻辑。本文旨在解决视觉观测下如何生成满足复杂时序逻辑的轨迹，填补感知与形式化规划间的鸿沟，实现无需特权几何信息的端到端规划。
—

方法Method

整体流程为：坐标无关的 TL 图编码 -> 多视图视觉 Token 生成 -> 双向交叉注意力融合 -> Flow Matching 轨迹生成。创新点包括：1) 用物体 ID 嵌入替代坐标，构建无坐标 TL 图，避免泄露几何信息；2) 视觉 Token 仅含归一化网格和视角 ID，保留空间可寻址性；3) 引入双向交叉注意力实现图与视觉互条件，让逻辑节点查询视觉证据；4) 训练时添加谓词到对象的接地损失，强制注意力聚焦目标物体。最终通过流匹配生成轨迹，利用 ODE 积分从噪声分布映射到数据分布。
—

实验Experiments

在 Panda 操作和 AntMaze 导航仿真域测试。基线包括 Oracle State 和 Visual Fusion。指标为 Success@K。结果显示 Vision-TL-Action 在 Panda 上 Success@1024 达 67.45%，优于 Oracle 的 59.11%；AntMaze 上 96.35% 接近 Oracle 的 96.88%。消融表明视觉输入和接地损失显著提升性能，但单样本成功率仍低于已知状态，需依赖采样多样性。分辨率研究指出 16x16 网格对 AntMaze 至关重要，防止目标碰撞。
